# Mywebsite.

Landing page pessoal de portfólio — Micael Eduardo, desenvolvedor de sites em Salvador, BA.

HTML/CSS/JS puro, sem build step. GSAP para animações de scroll e uma fita de cetim em WebGL como fundo animado do hero e do CTA final.

## Estrutura

- `index.html` — página única
- `css/style.css` — estilos
- `js/script.js` — animações (GSAP/ScrollTrigger)
- `js/satin-ribbon.js` — shader WebGL do fundo animado
- `assets/` — imagens, ícones e favicons

## Rodar localmente

Qualquer servidor estático funciona, por exemplo:

```
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
